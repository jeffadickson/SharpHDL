Independent recurrence models cover:
- Running sum with nonzero reset seed and uint wraparound.
- Conditional checksum plus count, atomically updated or cleared.
- Previous-value output captured before the new state assignment.
- Exact continuously-ready external latency and II = latency + 1 by default, or latency with forwarding.
- Randomized input/output stalls; no stale-state admission.
- State frozen until output acceptance; one in-flight iteration matches occupancy.
- Reset during blocked output, computation, and commit/replacement; seed
  restoration and discard accounting.
- Simultaneous commit/accept forwards all next state and keeps busy set.
- Explicit rejection of stateless bodies, checked operations and nested cycles
  through the feedback API before creating state registers.

Generated schedules report external recurrence behavior separately from the
internal elastic datapath. These tests do not establish target-device timing,
optimal initiation intervals, modulo scheduling or resource sharing.
