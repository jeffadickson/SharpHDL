SharpHDL 0.6 verification — 2026-10-13 UTC

C# (Mono compilation and execution):
  15,212 base + 49,234 feature + 6,698 numeric = 71,144 assertions passed.
F# (direct .NET 8 C#/F# compilers and execution):
  8,597 assertions passed; eight F# designs generated and tested.

New checks cover typed widening and fixed-point nearest-even saturation;
independent exact-rational float add/subtract/multiply/divide references;
float precision conversions; math accuracy using quantized-input double
references; extreme exponent samples; NaR, canonical zero and domain rules;
skid capacity/order/sidebands/reset/latency/throughput/ready independence;
and C#/F# gain and complex-power pipelines with backpressure.

Icarus Verilog differential tests:
  67 C#-generated RTL benches passed.
  Eight F#-generated RTL benches passed; AXI wrappers compiled.

Yosys structural RTL synthesis and post-synthesis trace simulation passed for:
  SkidBuffer16, QuantizedGain24, Float16_add, Float16_mul, Float16_div,
  Float16_sqrt, Float16_log2, Float16_cos.
  Used proc -norom to keep explicit coefficient case logic.

Largest observed normalized error |actual-reference|/max(1,|reference|):
  Tiny16 math: 0.00539015 (sampled power).
  Compact24 math: 0.000063477 (sampled power).
These are sampled maxima, not proven bounds or universal tolerances.
See generated/numeric_accuracy.txt and individual test cases for ranges.

Custom finite formats are not IEEE 754 or historical Level II binary compatible.
No FPGA placement/routing, resource budget, clock rate or board validation.
The new float functions are direct combinational networks; stream adapters
add output storage but do not internally pipeline long arithmetic paths.
MSBuild remains unavailable in this environment; the SDK compilers were
invoked directly, as documented in examples/FSharp/build_direct.py.
