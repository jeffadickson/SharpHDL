# Illustrated course assets

The course contains 15 illustrations: one generated cover and 14 original,
exact teaching diagrams. Each diagram is supplied as editable SVG and a
high-resolution PNG export. The DOCX includes 16 tables and 15 pages.

Regenerate the exact diagrams with `tools/create_course_diagrams.py`
(requires CairoSVG), then build the workbook with
`tools/create_classroom_proposal.py` (requires python-docx). The included cover
is consumed directly by the workbook builder; it is not regenerated by those
scripts. Image descriptions are included in the DOCX for accessibility.

## Teaching figures

- board: conceptual Go Board feature map; not a physical placement guide.
- binary_cards: 1101 = thirteen, using place values 8, 4, 2, 1.
- gates: correct AND/OR outputs for the same inputs 1 and 0.
- adder: 0011 + 0010 = 0101.
- overflow: five-bit 10000 narrowed to four-bit 0000.
- memory and clock: stored state and rising-edge capture.
- counter: exact low-bit states from zero through three.
- pipeline: add-two and multiply-three stages with register boundaries.
- skid: head/spill storage and a receiver wait.
- languages: actual F# / C# / Visual Basic hardware composition.
- hockey: shot-counter capstone concept, not an implemented decimal scoreboard.
- printable_cards: physical 8 / 4 / 2 / 1 cards.
- segments: conventional A..G labels and the correct five segments for digit 2.

The exact numerical figures are authored in code rather than inferred from
AI-generated diagrams. The cover is expressive, intentionally stylized art;
its props are not a product photograph or an exact board schematic.

## Cover generation record

Mode: built-in image-generation tool. No API-key CLI was used.
Asset: `docs/course-art/cover.png`.

Prompt:

Use case: illustration-story. Create a polished wide children's science
workbook cover illustration for an age-ten digital hardware class. Two curious
ten-year-old children, a girl and a boy, with a friendly small robot mentor at
a classroom workbench, looking at a small FPGA circuit board with glowing
colored LEDs and two seven-segment displays. Warm, welcoming hand-painted
picture-book style with crisp shapes, teal, orange and sunny yellow accents,
white/light cream surroundings, generous airy negative space. Show number
cards and a laptop as supporting objects, conveying discovery and teamwork.
The circuit board is a stylized educational prop, not a technical diagram or
an exact product photo. No text, letters, numbers, labels, logos, watermarks,
or symbolic equations anywhere, including on the laptop and cards. Landscape
banner composition, approximately 2:1, suitable for the upper half of an
illustrated workbook cover.

The resulting cover displays stylized lit segment shapes. It is labeled as
imaginative cover art in the workbook; only the original diagrams carry the
course's exact numerical examples.
