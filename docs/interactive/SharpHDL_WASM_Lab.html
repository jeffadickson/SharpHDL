How to read it

Time goes from left to right. A rising clock edge is a step upward. Next rising edge visits those clock transitions; Next event can also visit input changes or falling edges. A bus label is the number held during that interval. Click a waveform or move the cursor to inspect values.

“x” and “z” mean an unknown or undriven value, never zero. Bus values here are unsigned. Testbench delays arrange experiments; they do not predict an FPGA’s physical speed.

Teacher setup
From the repository root, run python3 -m http.server 8090 --directory docs. Open http://localhost:8090/interactive/SharpHDL_WASM_Lab.html. For offline engine use, first run python3 tools/fetch_verisim_runtime.py, then check Use downloaded engine. The initial download requires internet.
